## 🎯 Executive Summary

Delivered a hands-on technical workshop and live cybersecurity demonstration during **Induction – Emerge 2026** at **Graphic Era Deemed to be University**. Guided by **Prof. Darshan Singh** and **Prof. Mukesh Bhandari**, and co-instructed alongside **Aastik Gupta** and **Nishil Bhimani**, the session transformed theoretical cybersecurity paradigms into practical engineering systems, hardware reconnaissance, and active defense mechanics.

---

## 🔬 Core Demonstrations & Key Modules

### 1. ⚙️ Custom IoT Security Hardware Tool Demonstration
- **Hardware-Level Reconnaissance**: Demonstrated how custom-built IoT hardware can probe local environments, discover connected devices, and capture network telemetry.
- **Behavioral Analysis**: Monitored live traffic patterns across connected nodes to detect anomalies, unauthorized broadcast packets, and misconfigured IoT interfaces in a sandboxed, ethical environment.

### 2. 📁 FluxDrop — Cryptographic Secure File Transfer
- **Architecture Showcase**: Demonstrated **FluxDrop**, a privacy-first secure file-transfer platform designed to eliminate man-in-the-middle interception, eavesdropping, and unauthorized data leakage during transit.
- Explored cryptographic integrity checks and tamper detection in real-world networking.

### 3. 🛠️ IoT Security & Ethical Hacking Frameworks
- Practical analysis of IoT device attack surfaces, default credential vulnerabilities, unencrypted communications, and hardware bus debugging.
- Teaching structured security audits and proactive vulnerability identification before deployment.

### 4. 🕵️ Wireshark & Burp Suite in Action
- **Packet Inspection with Wireshark**: Live capture of network packets, protocol analysis (TCP/UDP, DNS, HTTP), and identifying cleartext leaks.
- **Web App Security with Burp Suite**: Intercepting and analyzing HTTP requests, parameter tampering, and assessing API endpoints.
