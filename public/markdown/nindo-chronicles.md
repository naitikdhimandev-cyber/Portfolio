# 🌀 Nindo Chronicles — Naruto Shippuden Web Zine
### Immersive Anime-Themed Web Experience

An interactive web zine and anime showcase featuring cinematic parallax scrolling, animated character showcases, custom audio integrations, and interactive storytelling — built for a frontend UI hackathon.

🔗 [GitHub Repository](https://github.com/naitikdhimandev-cyber/Naruto_Zine-UI_Hackathon_Project-) &nbsp;&nbsp; 🌐 [Live Demo](https://naitik615.github.io/naruto-zine/)

---

## 🎯 Overview

Nindo Chronicles is a high-aesthetic frontend showcase inspired by the Naruto Shippuden universe. Built to demonstrate advanced CSS animations, interactive scroll effects, and media handling, it brings anime lore to life with fluid animations and responsive design.

---

## ✨ Key Features

- **Cinematic Hero Sections**: Dynamic visual hero headers with audio theme integration.
- **Interactive Character Cards**: Animated hover states, stat overlays, and lore breakdown cards.
- **Parallax & Scroll Animations**: Smooth CSS keyframes and JavaScript scroll observers.
- **Audio Soundboard**: Integrated Web Audio sound effects and background music controls.

---

## 🛠️ Tech Stack

| Layer | Technology |
|:---|:---|
| **Frontend** | HTML5, CSS3 (Custom CSS Animations & Grid) |
| **Interactivity** | Vanilla JavaScript (ES6+) |
| **Hosting** | GitHub Pages |

---

## 🧩 Challenges & Key Learnings

- **Performance & Asset Loading**: Balancing high-res images and audio clips without breaking page load speed using lazy loading and asset compression.
- **Cross-Browser CSS Keyframes**: Crafting smooth multi-layer keyframe animations that render consistently at 60fps across desktop and mobile devices.
